# WipeFilter : téléchargements

Ce dépôt contient uniquement les fichiers à télécharger de **WipeFilter** (Windows 10 et 11). Aucun code source.

- **Recommandé : [Microsoft Store](https://apps.microsoft.com/detail/9N8336HC2NKM)** : signé par Microsoft, sans alerte SmartScreen, mises à jour automatiques.
- Option : `WipeFilter.exe` dans les [Releases](https://github.com/Gremzyto/wipefilter-releases/releases/latest) (non signé, Windows peut afficher SmartScreen). L'empreinte SHA-256 est dans `WipeFilter.exe.sha256`.
